# WhatsApp Admin Panel - React + Supabase + Gemini AI

A comprehensive admin panel for managing WhatsApp campaigns with AI-powered template generation.

## Features

- 🔐 **Authentication**: Secure login with JWT tokens
- 👥 **Client Management**: Full CRUD operations for clients
- 📦 **Plan Management**: Create and manage subscription plans
- 📝 **AI Templates**: Generate WhatsApp message templates with Gemini AI
- 📨 **Campaign Management**: Create and schedule WhatsApp campaigns
- 📊 **Dashboard**: Analytics and upcoming expirations
- 📥 **Bulk Import**: CSV/XLSX import for clients
- 🌓 **Dark Mode**: Theme toggle with persistence
- 🔔 **Toast Notifications**: User feedback system
- 📱 **Responsive Design**: Mobile-friendly interface

## Tech Stack

- **Frontend**: React 18, Vite, TailwindCSS, Framer Motion
- **Backend**: Supabase (PostgreSQL, Edge Functions)
- **AI**: Google Gemini API
- **WhatsApp**: W-API Integration
- **UI Components**: Custom components with shadcn/ui patterns
